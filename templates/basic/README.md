# My TypeScript app

Scaffolded with [create-tsx-app](https://github.com/mattiamalonni/create-tsx-app).

## Getting started

```bash
npm install
npm run dev
```

Edit `src/index.ts` and save to see changes immediately.

## Scripts

- `npm run dev` — run with hot reload via `tsx`
- `npm run build` — compile to `dist/` as native ESM
- `npm start` — run the compiled app
- `npm run type-check` — check types without emitting
- `npm run lint` / `npm run format:check` — Oxlint and Oxfmt (when enabled)

Requires Node.js >= 22.18. Replace `npm` with your package manager if you used another one.
